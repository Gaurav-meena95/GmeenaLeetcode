## Problem Description
Chase Possible

Chef is playing a cricket match and needs to score at least RRR more runs off the last BBB balls to win the match.

Chef's opponent is really strong, so they won't let him get any extra runs (wides, no-balls, etc.); and hence Chef can only get at most 666 runs from each ball.

Is it possible for Chef to still win the match? Print Yes\text{Yes}Yes if possible, and No\text{No}No otherwise.

Input Format

- The first and only line of input contains 222 integers - RRR and BBB.

Output Format

Output Yes\text{Yes}Yes if Chef can still win, and No\text{No}No otherwise.

Each letter of the output may be printed in either uppercase or lowercase, i.e. the strings no,No,nO,\text{no}, \text{No}, \text{nO},no,No,nO, and NO\text{NO}NO will all be treated as equivalent.

Constraints

- 1≤R≤3001 \le R \le 3001≤R≤300

- 1≤B≤1201 \le B \le 1201≤B≤120

Sample 1:
InputOutput
```
36 6
```

```
Yes
```

Explanation:

Chef can still hit 666 666s in the next 666 balls to win the match.

Sample 2:
InputOutput
```
50 8
```

```
No
```

Explanation:

It is impossible for Chef to win.
