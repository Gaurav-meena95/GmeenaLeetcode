## Problem Description
Game Controller

Chef is playing a game where his character starts at position 000.

Pressing the right button moves the character 111 step to the right. Pressing the left button moves it 111 step to the left.

Chef presses the right button RRR times and the left button LLL times. Find how many steps the character is from its starting position after all the presses.

Input Format

The only line contains two space-separated integers RRR and LLL.

Output Format

Print the number of steps between the character's final position and its starting position.

Constraints

- 0≤R,L≤1000 \le R, L \le 1000≤R,L≤100

Sample 1:
InputOutput
```
3 8
```

```
5
```

Explanation:

The character finishes 555 steps to the left of its starting position, so the distance is 555.

Sample 2:
InputOutput
```
4 4
```

```
0
```

Explanation:

The character returns to its starting position.

Sample 3:
InputOutput
```
10 2
```

```
8
```

Explanation:

The character finishes 888 steps to the right of its starting position, so the distance is 888.
